# noroo-punchlist

[English](README.md) | **한국어**

여럿이 함께 쓰는 하자 점검 목록입니다. 모두 휴대폰으로 같은 페이지를 열고 하자를 사진과 함께 등록하면, 목록이 모든 사람의 화면에 실시간으로 반영됩니다.

새 아파트 입주 전 사전점검용으로 만들었습니다. 여러 사람이 동시에 방을 돌아다니며 점검하고, 발견한 하자를 전부 하나의 목록으로 모아야 하는 상황을 위한 앱입니다.

## 기능

- **하자 등록.** 위치, 설명, 사진(최대 5장)을 입력합니다.
- **실시간 목록.** 새로 등록하거나 수정한 항목이 WebSocket으로 모두의 화면에 바로 나타납니다.
- **수정과 삭제.** 내용을 고치고 사진을 추가하거나 뺄 수 있습니다. 삭제하면 목록에서는 사라지지만 기록과 사진은 디스크에 남습니다.
- **공용 비밀번호 하나.** 계정이 없습니다. 비밀번호를 아는 사람은 누구나 읽고 쓸 수 있고, 한 번 로그인하면 30일간 유지됩니다.
- **데이터베이스 없음.** 항목은 JSON 파일 하나에, 사진은 `data/` 아래 파일로 저장됩니다.

## 실행

```
npm install
APP_PASSWORD=<비밀번호> SESSION_SECRET=<길고-무작위인-문자열> npm start
```

그다음 `http://localhost:8000`을 엽니다.

Docker로 실행할 수도 있습니다.

```
APP_PASSWORD=<비밀번호> SESSION_SECRET=<길고-무작위인-문자열> docker compose up --build
```

compose 파일은 `127.0.0.1:9001`에 바인딩하고 `dbnet`이라는 외부 Docker 네트워크에 참여합니다. [noroo-deploy](https://github.com/tinynoroo/noroo-deploy)로 관리하는 서버용으로 작성했기 때문입니다. 단독으로 실행하려면 네트워크를 먼저 만들거나(`docker network create dbnet`) `networks` 줄을 지우세요.

| 변수 | 의미 |
|---|---|
| `APP_PASSWORD` | 공용 비밀번호. 필수 |
| `SESSION_SECRET` | 로그인 쿠키 서명 키. 필수 |
| `PORT` | 사용할 포트 (기본값 `8000`) |
| `DATA_DIR` | JSON 파일과 사진을 저장할 위치 (기본값 `./data`) |

## 알아둘 점

- 사진 업로드 용량 제한이 없습니다. 서버가 인터넷에 열려 있다면 리버스 프록시에서 제한을 거세요.
- 이미지 파일만 받습니다.
- 소수의 사람이 며칠 동안 쓰는 용도로 만들었습니다. 여러 팀이 함께 쓰는 서비스가 아니며, 목록도 비밀번호도 하나뿐입니다.

## 스택

Node.js, Express, `ws`, `multer`. 서버 파일 하나와 HTML 페이지 세 개로 되어 있고, 빌드 과정이 없습니다.
